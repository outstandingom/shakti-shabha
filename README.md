# Shakti Sabha — React + TypeScript + GSAP

> Union of Peace & Revolution · Digital Platform

## Quick Start

```bash
npm install
npm run dev
```

Open: `http://localhost:5173`

## Stack
- **React 18** + **TypeScript**
- **GSAP 3** with ScrollTrigger — all animations
- **Lenis** — smooth scroll
- **React Router v6** — client-side navigation
- **Vite 5** — build tool
- **CSS Modules** — scoped styles

## GSAP Animations Per Section
| Section | Effect |
|---|---|
| Hero | Word split load, parallax fire/peace layers, ember particles |
| Profile | Clip-path photo reveal, stagger text |
| Aaryaveera | Title Y-clip reveal, breathing gold glow |
| Social Work | CountUp numbers on scroll enter |
| Events | Stagger with rotateX |
| Courses | **Pinned horizontal scroll strip** |
| History | Timeline cascade + figCard scale pop |
